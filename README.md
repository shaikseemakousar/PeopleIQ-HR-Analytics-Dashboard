# PeopleIQ - HR Analytics Dashboard

## Project Overview
PeopleIQ is an HR Analytics Dashboard developed using Microsoft Power BI to analyze employee data and generate meaningful workforce insights.  

The dashboard helps organizations monitor employee attrition, workforce demographics, salary trends, and department performance using interactive visualizations and KPI metrics.

---

# Objectives

- Analyze employee attrition trends
- Monitor workforce demographics
- Track salary and tenure insights
- Improve HR decision-making
- Build interactive executive-level reports
- Visualize employee distribution across departments

---

# Tools & Technologies Used

| Tool | Purpose |
|---|---|
| Power BI | Dashboard Development |
| Power Query | Data Cleaning & Transformation |
| DAX | KPI Calculations |
| Excel / CSV | Dataset Source |

---

# Dashboard Features

- Executive KPI Cards
- Attrition Analysis
- Gender Distribution Analysis
- Department-wise Insights
- Salary Analysis
- Employee Tenure Tracking
- Interactive Filters & Slicers
- Modern UI Dashboard Design
